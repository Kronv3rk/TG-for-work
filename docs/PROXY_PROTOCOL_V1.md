# PROXY protocol v1 в TG-for-work

Оригинал `Flowseal/tg-ws-proxy` поддерживает заголовок
`PROXY TCP4` / `PROXY TCP6` для установки прокси за NGINX или HAProxy.
В Android эта возможность реализована **как дополнительная, выключенная
по умолчанию настройка** «Принимать заголовок PROXY protocol v1».

При включении приложение ожидает в начале каждого TCP-подключения строку
в формате PROXY protocol v1, перед обычным MTProto-рукопожатием или Fake TLS.
Строка должна заканчиваться `CRLF`, содержать не более 107 байт и иметь
корректные IPv4/IPv6-адреса и номера портов. Допускается `PROXY UNKNOWN`.
После заголовка оставшиеся байты читаются как прежний поток Telegram.

**Важно:** этот протокол не шифруется и не подтверждает подлинность
адреса отправителя. Включайте его только за собственным доверенным
reverse proxy. Для прямых подключений Telegram или работы на обычном
локальном адресе переключатель должен оставаться выключенным.

Поддержка проверяется модульными тестами. Работа в реальной конфигурации
NGINX/HAProxy на телефоне нуждается в отдельном сетевом тесте.
