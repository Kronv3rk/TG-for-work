# Интерфейс TG-for-work: обновление от 5 ноября 2026 года

## Что изменено

- Главный экран показывает состояние локального прокси, адрес, два показателя активности, маршрутизацию и основные действия.
- Статусы различают остановленный сервер, работающий локальный слушатель и наличие подключений клиента. Ни одно состояние не утверждает, что удалённый Telegram DC доступен без проверки.
- Длинный журнал скрыт в раскрываемом разделе. В нём есть отдельная кнопка копирования журнала и перезапуск прокси.
- Ссылка на прокси копируется без запуска локального сервера.
- Настройки сгруппированы: локальное подключение, безопасность, маршруты, производительность.
- Секрет скрыт по умолчанию. Ошибки привязаны к полям ввода, а ошибочный ввод не закрывает диалог.
- Кнопки и строки действий имеют минимальный размер для касания, карточки умеют расти по высоте при увеличении системного шрифта.
- Светлая и тёмная палитры нейтральные. Цвета текста рассчитаны с контрастом минимум 4,5:1 на основной и акцентной поверхностях.
- На Android 15+ добавлена обработка системных insets для корневой прокрутки.
- Обновление UI приостанавливается, когда Activity не видна.

## Проверки без GitHub Actions

- XML-файлы главного экрана, настроек, быстрых действий и цветов проверены на сбалансированную структуру.
- Ссылки на 42 идентификатора элементов из Activity и 140 строковых ресурсов согласованы, отсутствующих ссылок и дубликатов не найдено.
- Проверены все 10 полей EditText: каждому соответствует labelFor и минимальная высота 52dp.
- Проверены 9 кнопок: минимальная высота не меньше 48dp.
- Проверено совпадение 21 роли цвета в дневной и ночной палитрах.
- 13 автономных проверок Kotlin/JVM для ConnectionPhase и ProxyLinkFormatter прошли на локальном JDK.
- Бинарная идентичность этих двух Kotlin-файлов подтверждена совпадением Git blob SHA-1.
- HTML-предпросмотр использован только для проверки композиции: это НЕ рендер Android XML и НЕ скриншот APK.

## Оставшиеся обязательные проверки

- Сборка Android SDK: ./gradlew :app:testDebugUnitTest :app:assembleDebug
- Визуальное тестирование Android на ширине 320dp, обычном экране, горизонтальной ориентации.
- Настройки размера шрифта 100%, 150% и 200%, включая открытый диалог с клавиатурой.
- TalkBack, переключатели и все доступные действия без жестов длительного нажатия.
- Android 15/16: status/navigation bars, вырезы, жестовая навигация и клавиатура.
- Смена языка системы, поворот экрана, сохранение введённых значений, работа в тёмной теме.
- Установка поверх действующей релизной версии пока НЕ подтверждена.

## Совместимость веток

Ветка design/clear-dashboard-20261105 начинается от main 1.9.1.
Она независима от сетевых PR #19 и #20, поэтому при объединении с ними возможны конфликты в MainActivity.kt и ресурсах. Исправления конфликтов и объединённый тестовый APK необходимы перед выпуском релиза.

Не открывайте PR ради запуска CI, пока не выполнены доступные локальные проверки.
