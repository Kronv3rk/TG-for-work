# Подключение через Cloudflare

TG-for-work 2.0.0 сначала использует защищённое соединение TLS. Если оно не отвечает, приложение может выбрать резервный WebSocket без внешнего TLS. Выбранный транспорт отображается на главном экране: «CF TLS» или «CF без TLS».

Без внешнего TLS посредники в сети могут видеть метаданные и вмешиваться в обмен. Шифрование MTProto сохраняется, но не заменяет проверку подлинности TLS-сервера.

Чтобы использовать только защищённые маршруты Cloudflare, откройте расширенные настройки и отключите «Разрешить резервный Cloudflare без TLS» и ручной режим без TLS. Приложение не отключает проверку TLS-сертификатов.
