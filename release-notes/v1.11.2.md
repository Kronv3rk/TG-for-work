# TG-for-work 1.11.2

Синхронизация сетевых механизмов с оригиналом `Flowseal/tg-ws-proxy` 1.11.4 (основная ветка до 6 ноября 2026 года).

- **HTTP/2 без потери уже полученных медиа-пакетов.** Если другой параллельный поток завершается ошибкой, ранее принятые ответы сначала передаются Telegram. Резервирование памяти освобождается при закрытии соединения.
- **Fake TLS.** Длина первого зашифрованного TLS-рекорда берётся из заголовка, без ожидания всего содержимого. Проверка HMAC выполняется за постоянное время. Для opt-in Domain Fronting проверяется имя сертификата SNI, а не только цепочка доверия.
- **Cloudflare Worker.** Дублирующиеся домены не расходуют попытки подключения и не сбрасывают готовый пул. Исправление работает и в прямом Worker fallback.
- **Тестовые дата-центры Telegram.** Автоматическое распознавание DC `10001–10003`, тестовые IP-адреса, путь `/apiws_test`, отсутствие маршрутизации через обычный Cloudflare Proxy/H2. Добавлен выключенный по умолчанию переключатель принудительной тестовой среды для клиентов без маркера `+10000`.

Проверены JVM-регрессии, интеграционные тесты с локальным TLS/HTTP/2-сервером и сборка APK. Настоящие соединения с Cloudflare и тестовыми серверами Telegram, а также длительная работа на физических Android-устройствах ещё требуют испытаний. Поэтому **HTTP/2 для медиа остаётся экспериментальным и отключённым по умолчанию**.

Идентификатор приложения, сохранённые настройки, формат `tg://proxy` и действующий сертификат подписи APK сохранены. Установка поддерживается поверх версии 1.11.1.
