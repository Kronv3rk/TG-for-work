# TG-for-work 2.0.0

## Обновление

Новая версия подписывается новым сертификатом. Если установлена версия 1.x, сохраните необходимые параметры прокси, удалите старое приложение и установите APK с официальной страницы GitHub Releases. Затем добавьте новую ссылку в Telegram. Последующие выпуски с новым сертификатом устанавливаются поверх 2.0.0.

## Изменения

- Автоматический выбор публичного Cloudflare-транспорта и домена; резервный WebSocket без внешнего TLS включён по умолчанию, его можно отключить.
- Адаптивный интерфейс, светлая и тёмная темы, сохранение черновика настроек при повороте.
- Исправлены повторные попытки соединения и обработка закрытых сокетов.
- Защищённый процесс релизной сборки и проверка подписи.

Проверены реальные ответы MTProto на эмуляторах API 35–37, восстановление после сетевого обрыва и синтетическая двусторонняя нагрузка 128 МиБ через локальный стенд. Реальные медиафайлы Telegram и физические устройства не проверялись.
