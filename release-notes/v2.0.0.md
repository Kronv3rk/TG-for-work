# TG-for-work 2.0.0

- Улучшен автоматический выбор маршрутов и восстановление после обрыва связи.
- Обновлён интерфейс: системная, светлая и тёмная темы, адаптация к размеру окна и шрифта.
- Настройки сохраняют несохранённые значения при повороте экрана.
- Добавлен автоматически выбираемый резервный Cloudflare-транспорт без внешнего TLS, который можно отключить в расширенных настройках.

## Обновление с версии 1.x

Сохраните нужные параметры прокси, удалите старое приложение и установите новый подписанный APK из GitHub Releases. Затем добавьте новую ссылку в Telegram. Последующие версии с тем же сертификатом можно устанавливать поверх 2.0.0.

Обмен MTProto проверен на эмуляторах Android 15–17. Экспериментальный HTTP/2 отключён по умолчанию.
