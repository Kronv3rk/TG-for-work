# TG-for-work 1.11.4

Продолжение функциональной синхронизации с оригиналом `Flowseal/tg-ws-proxy` v1.11.4.

- **Строго ограниченное время обработки неверного MTProto-рукопожатия.** Исправлен сценарий, при котором клиент мог отправлять по одному байту почти каждые десять секунд и тем самым бесконечно занимать рабочий поток. Теперь действует единый монотонный предел десять секунд, а сторожевой таймер прерывает и вложенные чтения Fake TLS. Лимит 64 КиБ сохраняется.
- **Поддержка аналога `--no-secure` оригинала.** Добавлена необязательная настройка «Cloudflare без TLS (порт 80)» для соединений Cloudflare Proxy и собственного Worker, включая прогретые соединения Wi-Fi-пула. Режим позволяет использовать `ws://`, когда защищённые WebSocket недоступны.
- **Безопасный режим не меняется.** Опция порта 80 выключена по умолчанию, прямые Telegram WebSocket, Domain Fronting и HTTP/2 продолжают использовать TLS. Интерфейс предупреждает о том, что при `ws://` сеть может наблюдать и модифицировать трафик.
- Добавлены регрессионные тесты общего тайм-аута, выбора порта 80/443, требования TLS для Domain Fronting и неизменности конфигурации по умолчанию.

Сохраняются существующий идентификатор Android-приложения, `tg://proxy`, пользовательский секрет и сертификат подписи релизного APK.

**Оставшиеся проверки:** совместимость HTTP/2 с реальными Cloudflare `/api`, тестовые серверы Telegram, работа порта 80 на реальных Cloudflare Proxy/Worker и длительные испытания на физических Android-устройствах. HTTP/2 остаётся экспериментальным и выключенным по умолчанию; полное технологическое соответствие пока не подтверждено.
