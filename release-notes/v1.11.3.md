# TG-for-work 1.11.3

Продолжение синхронизации с оригинальным `Flowseal/tg-ws-proxy` 1.11.4.

- **Обработка неверного MTProto-рукопожатия.** Вместо немедленного разрыва соединения приложение дочитывает не более 64 КиБ входящего потока с тайм-аутом 10 секунд, как в оригинале. Это уменьшает различия сетевого поведения между реализациями и не даёт ошибочному соединению удерживать поток без ограничения.
- **PROXY protocol v1.** Для работающего за собственным NGINX или HAProxy Android-прокси добавлена поддержка заголовков `PROXY TCP4`, `PROXY TCP6` и `PROXY UNKNOWN`. Применяются ограничение длины 107 байт, проверка синтаксиса и адресов; заголовок удаляется перед обычным MTProto/Fake TLS.
- **Безопасность настройки.** Новый режим отключён по умолчанию. Он предназначен только для доверенного обратного прокси: PROXY v1 сам по себе не удостоверяет IP-адрес отправителя и не нужен при обычном прямом подключении Telegram.
- Добавлены тесты неправильных и обрезанных заголовков, корректных IPv4/IPv6, сохранения MTProto-данных после заголовка и ограниченного чтения ошибочных рукопожатий.

Существующие маршруты, пользовательские настройки, секрет и формат `tg://proxy` сохраняются. Сохраняется действующий сертификат подписи APK. Новая версия предназначена для установки поверх **v1.11.2**.

**Полное соответствие оригиналу пока не подтверждено:** для экспериментального HTTP/2 и Fake TLS по-прежнему нужны испытания с реальными серверами Cloudflare, производственными и тестовыми дата-центрами Telegram, а также длительные тесты на физических Android-устройствах. HTTP/2 выключен по умолчанию.
