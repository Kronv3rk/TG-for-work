# TG-for-work 1.11.5

Исправлена обработка недоступных WebSocket-адресов Telegram.

- После тайм-аута адрес временно исключается из клиентских подключений. Повторная проверка проводится в фоне, без задержки запросов Telegram.
- Успешная фоновая проверка возвращает адрес в маршрутизацию; неудачная продлевает ожидание.
- Проверки выполняются отдельно от клиентских рабочих потоков. Смена сети сбрасывает старое состояние.
- Устранено повторное планирование проверок одного адреса.
- Добавлены модульные тесты восстановления маршрутов.

**Проверено:** модульные тесты и сборка отладочного APK в GitHub Actions для коммита 31e931a.

**Не проверено:** поведение на физическом Android-устройстве и длительная работа с реальными серверами Telegram. До публикации релиза необходимо проверить сертификат подписи и исключить резервный ключ из Git-истории/релизного процесса.
