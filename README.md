# TG-for-work

Локальный MTProto-прокси для Telegram на Android. Приложение основано на [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) и не требует собственного сервера для обычного подключения.

**[Скачать APK](https://github.com/Kronv3rk/TG-for-work/releases/latest)** · [Все версии](https://github.com/Kronv3rk/TG-for-work/releases) · [Сообщить об ошибке](https://github.com/Kronv3rk/TG-for-work/issues/new)

## Возможности

- Автоматический выбор доступного маршрута к Telegram.
- Работа прокси в фоне с постоянным уведомлением.
- Открытие Telegram и копирование ссылки на локальный прокси.
- Светлая, тёмная и системная темы; адаптация к размеру экрана и шрифта.
- Просмотр состояния соединения и настройка параметров подключения.

## Установка и подключение

1. Скачайте подписанный APK с официальной страницы релизов. Android может запросить разрешение на установку из этого источника.
2. Установите приложение и нажмите «Запустить прокси».
3. Нажмите «Открыть Telegram» и подтвердите подключение.
4. Если соединение пропадает при выключенном экране, разрешите приложению работу в фоне в системных настройках.

По умолчанию прокси слушает адрес 127.0.0.1:1443. Если Telegram не открылся автоматически, скопируйте ссылку из приложения и откройте её вручную.

## Обновление

Скачайте новый подписанный APK из GitHub Releases и установите поверх предыдущей версии.

При переходе с 1.x на 2.0.0 потребуется однократно удалить старое приложение из-за смены сертификата подписи. Предварительно сохраните нужные настройки прокси. После установки 2.0.0 добавьте новую ссылку в Telegram. Последующие выпуски с тем же сертификатом устанавливаются обычным обновлением.

## Настройки и безопасность

В обычном режиме ручная настройка не требуется. Если защищённый маршрут Cloudflare не отвечает, версия 2.0.0 может переключиться на резервный WebSocket без внешнего TLS. При необходимости этот режим можно отключить. [Подробнее о выборе транспорта](docs/CLOUDFLARE_PLAINTEXT.md).

Не передавайте ссылку прокси и его секрет посторонним. Загружайте APK только из официального раздела Releases.

## Если Telegram не подключается

Проверьте, запущен ли прокси, и повторно добавьте ссылку в Telegram. После изменения адреса, порта или секрета используйте новую ссылку. При нестабильной сети попробуйте переподключиться.

Если проблема сохраняется, сообщите версию приложения, Android и тип сети в Issues. Не публикуйте секреты, ссылки подключения, токены и личные данные.

## Совместимость

Требуется Android 7.0 (API 24) или новее. Обмен с Telegram в версии 2.0.0 проверен на эмуляторах Android 15, 16 и 17. Доступность маршрутов зависит от сети. Экспериментальный HTTP/2 по умолчанию отключён.
